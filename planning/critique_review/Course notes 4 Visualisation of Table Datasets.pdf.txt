2.1 Vocabulary
Before discussing chart choices, we first clarify six terms that are often
used interchangeably but are not identical.
• Idiomis a reusable visual design pattern for data. In these notes,
words such as chart, plot, and map are treated as specific kinds of
idioms.1
• Graphis a general visual representation of relationships or values. In
different contexts, it can refer to a plotted function, a network struc-
ture, or a broad class of data graphics.
• Plotusually refers to a coordinate-based representation where data
is placed against explicit axes and scales. Scatterplots and line plots
are typical examples.
• Diagramis a schematic representation that emphasises structure,
flow, or concept relationships, often without precise quantitative
scales.

2.2 Idiom: Bar Charts
BriefA bar chart uses rectangular bars to compare values across cate-
gories. It is one of the most common comparison charts, and it is often
the first choice when the analysis goal is to compare magnitudes clearly.
What? A bar chart uses onecategorical key attributeand one
quantitative value attributeperitem. The key identifies category mem-
bership (one bar per category), and the value determines bar length from
a common zero baseline.
Figure 2.1:Elemental composition of a bar chart: category determines bar count, value determines bar height.
Why? The dominantactionsarequery(identify, compare, and
lookup category values) andsearch(find maxima, minima, or unusual
categories). The maintargetsare categorical groups and their quantita-
tive magnitudes.
How? At theidiomlevel, themarkisline(drawn as bars). The
primarychannelsarelengthon a common scale for quantitative value
andspatial region/orderfor category identity. This mapping is high in
effectivenessfor magnitude comparison; practicalscalabilityis usually
dozens to hundreds of items.

Use when
• Categorical comparison with close values.Bar charts are best suited for
comparing categorical data, especially when values are close together,
because people judge aligned length more accurately than area or
angle. 2
Avoid when
• Continuous data distribution.Bar charts require discrete categories
and visible gaps between bars. If the data is continuous, a histogram
is the correct idiom because bins are continuous intervals (see Fig-
ure 2.2).
• Truncated baseline manipulation.The core function of a bar chart
is comparison through length. If the y-axis does not start at zero,
proportional judgement becomes distorted and the visual difference
no longer matches the numerical difference.

preference. Research shows that truncated bar/column axes lead to
strong overestimation of differences. In a controlled 2015 study, par-
ticipants who saw deceptive charts interpreted the exaggerated message
more strongly (Pandey et al. 2015; Datawrapper 2025d).

Bar charts form a family of related idioms. A simple bar chart supports
direct comparison across categories; a grouped bar chart enables com-
parison between subgroups; a stacked bar chart combines totals with
composition; and a 100% stacked bar chart emphasises relative com-
position rather than absolute totals. In a 100% stacked chart, all bars
have equal length, so absolute values are intentionally suppressed. In
the following section, we discuss when to use stacked bar charts, when a
dot plot may be a better alternative, and when these designs should be
avoided.
2.2.1 Stacked Bar Chart
BriefA stacked column chart, also called a stacked bar chart, is used
to break a whole into parts while preserving category totals. Compared
with a simple bar chart, each category bar is divided into multiple subcat-
egories, usually distinguished by color.
What? Stacked bars add one extracategorical key attribute:
one key defines each bar, the second key defines the internal segment
category, and onequantitative value attributedefines segment size.

Design Guide
Use when
• Totals and composition matter together.Stacked bars are effective
when both total comparison and part-to-whole relationships are im-
portant, and when the number of categories and segments remains
manageable.
• Ordered categories with composition.When the primary key is ordered
(for example, time) and we want to show how composition changes
across that order, stacked bars can be useful if the number of segments
is not too large.
• Relative shares are more important than absolute totals.In this case,
100% stacked bars can highlight composition without emphasizing
total size.
• Short labels and compact category sets.Stacked bars work better
when labels fit naturally below each column and when the number of
categories is not too large.
Avoid when
• Precise part-to-part comparison across many totals.Most segments
do not share a common baseline, so exact comparison is hard. If this

2.2.2 Dot Plots
BriefA dot plot (sometimes called a dumbbell chart, barbell chart, or
gap chart) is a strong alternative to paired or stacked bar charts. It uses
symbols (often circles) and can connect paired points with a line or an
arrow. Data values map to one axis and groups to the other axis.
What? A simple dot plot maps onequantitative value attribute
peritem, with an optionalcategorical key attributefor grouping. A
connected dot plot adds another quantitative value per item to express
change between two states.
Why? The mainactionsarequery(precise value comparison),
search(outliers and ranges), andanalyse(direction/size of change in
connected variants). The primarytargetsare value differences, ranges,
and anomalies.
How? At theidiomlevel, themarkis apoint; the dominantchan-
nelis theposition on a common scale, which is highly effective for or-
dered comparison. Connected variants add a line or arrow mark to en-
code change;scalabilityis typically from a few to hundreds of items.
Figure 2.17:Dot-plot guidance (Datawrapper): use dot plots for precise low-ink comparison, connected dots for before/after gap reading,
and sorting for fast ranking scans.

2.3 Idiom: Line Charts
BriefA line chart is built from points connected by lines in a Cartesian
coordinate system. It is primarily used to show how values change over
time or across ordered categories.
What? A line chart uses oneordered key attribute(often time)
and onequantitative value attributeperitem. Optional series grouping
adds onecategorical key attribute.

2.3.1 Idiom: Area Charts
BriefAn area chart (also called an area graph) extends a line chart by fill-
ing the region between the line and the baseline. This fill adds a stronger
sense of magnitude and accumulated volume while still preserving trend
reading along an ordered axis. With a single series, it emphasises magni-
tude over time; with multiple series, the areas should be stacked vertically
rather than overlap, so the chart can still communicate both component
evolution and total change.
What? An area chart uses oneordered key attribute(usually
time) and onequantitative value attribute; multi-series area charts add
onecategorical key attributeand stack the series at each position.
Figure 2.30:Elemental composition of a single-series area chart: ordered x-axis, quantitative y-axis, and filled region under the trend line.
When an area chart expands from one filled series to multiple cate-
gories, the idiom changes from showing a single magnitude over time to
showing composition and total together. At that point, the series should
be stacked rather than overlaid, so readers can still interpret both the
whole and its parts.

coordinate system. It is the core idiom for reading relationships between
quantitative variables.
What? A scatterplot uses twoquantitative value attributesper

Idiom: Bubble Plot
BriefA bubble plot is a multivariate extension of the scatterplot. It keeps
x/y position for two quantitative variables and adds bubble size for a third
variable.
What? A bubble plot keeps twoquantitative value attributes
for x/y and adds a thirdquantitative value attributefor bubble size; an
optionalcategorical key attributecan be added for grouping.
Why? The maintasksarequeryandcompare, and the primary
targetis three-variablerelationshipreading in one view. A secondary
actionissearchfor size-related outliers or clusters when the size variable
is substantively important.
How? At theidiomlevel, themarkispoint, withareavariation
for the third quantitative value. The primarychannelsare position (x/y)
plus area size; optionalhuecan encode a categorical key. Forexpres-
siveness, size must be scaled by area (not radius).
Design Guide
Use when
• Compact multivariate comparison.Use bubble plots when three quan-
titative variables must be compared in one static view, and size differ-
ences are an important part of the message (see Figure 2.57).
