Mechanic definitions

Dice rolling: rolling dice decides what happens.

Roll / Spin and Move: move pieces by a roll.

Hand management: choosing which cards to keep or play.

Set collection: gathering matching groups of items.

Hexagon grid: moving or placing on six-sided spaces.

Cooperative game: all players work towards one shared goal.

Open drafting: taking turns to pick from shared items.

Simulation: modelling a real or imagined situation.

Variable player powers: each player has different abilities.

Tile placement: laying tiles to build a board.

Variable set-up: the starting layout changes each game.

Solo / Solitaire: the game can be played alone.

Tags: labelled symbols connect related cards and effects.
